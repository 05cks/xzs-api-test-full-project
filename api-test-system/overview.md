## 二、关键结论

1. **整体质量良好**：57 条自动化用例通过 56 条，权限控制、参数校验、异常处理均符合预期。
2. **发现 1 个严重安全缺陷**：
   **DEF-001 · 学生端拉卷接口泄露标准答案**——`/api/student/exam/paper/select/{id}`
   返回了 `correct`（标准答案）字段，E2E 测试已证明按该答案作答可拿满分。
   这是在线考试系统的**致命问题**，须优先修复（接口字段裁剪）。
3. 另发现 4 项中高风险：水平越权、分页无上限、RSA 私钥硬编码、CSRF 关闭。
4. **性能优秀**：接口平均响应 11.4ms，最慢 35.9ms。

## 三、关键决策

- **鉴权方式识别**：系统用 Spring Security 会话(Cookie) 而非 JWT，自动化采用 `requests.Session()` 保持会话。
- **密码处理**：库中密码为 RSA 密文，编写 `decrypt_pwd.py` 用私钥还原明文，解决自动化登录造数难题。
- **测试隔离**：所有用例时间戳命名 + 自清理，保证可重复执行、不污染业务库。
- **成果可回归**：套件支持按标记/关键字运行，可直接接入 CI。
