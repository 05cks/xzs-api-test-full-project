# 一、需求分析与测试范围

> 项目：学之思在线考试系统（xzs-mysql） · 被测算力：后台 API 层
> 技术栈：Spring Boot 2.1.6 + Spring Security + MyBatis + MySQL 8.0
> 服务地址：`http://localhost:8000` · 版本：xzs-3.9.0

---

## 1. 测试范围确认（三区域划分）

| 区域 | 定义 | 本系统对应内容 | 处理策略 |
|------|------|----------------|----------|
| **Zone 1 核心区** | 直接测试、完整分析的接口 | 认证、学科、题库、试卷/任务、学生答题、消息、用户管理、权限 | 全量分析并生成用例 |
| **Zone 2 交互区** | 有交互的外部模块 | 微信小程序端(`/api/wx/**`)、文件上传(七牛云)、Excel 导入 | 仅作背景知识，接口连通性抽测 |
| **Zone 3 外部区** | 无关内容 | 前端 Vue 页面、静态资源、部署脚本 | 排除 |

**结论**：本次测试聚焦 Zone 1 的 **8 大业务模块 + 1 安全域**，共 **40 个 REST 接口**（含管理端 22、学生端 18）。

---

## 2. 系统架构与接口约定

```
前端(Vue 管理端/学生端)
        │  HTTP + JSON（POST 为主）
        ▼
Spring Security 过滤器链 ── 登录鉴权 / 角色鉴权
        ▼
Controller(admin/student/wx) → Service → MyBatis Mapper → MySQL(exam)
```

**统一响应体**（`base.RestResponse`）：

```json
{ "code": 1, "message": "成功", "response": { } }
```

| 系统码 | 含义 | 触发场景 |
|--------|------|----------|
| 1 | 成功 | 业务正常 |
| 400 | 登录令牌失效 | remember-me/token 过期 |
| 401 | 用户未登录 | 未携带有效会话 |
| 402 | 用户名或密码错误 | 认证失败 |
| 500 | 系统内部错误 | 未捕获异常 |
| 501 | 参数验证错误 | `@Valid` 校验不通过 |
| 502 | 用户没有权限 | 角色不匹配 |

## 3. 鉴权机制分析（测试关键点）

| 项目 | 说明 | 测试影响 |
|------|------|----------|
| 登录接口 | `POST /api/user/login`，体 `{userName,password,remember}` | 认证用例基础 |
| 会话载体 | **Spring Security Session + JSESSIONID Cookie**（非 JWT） | 自动化须用 `requests.Session()` 保持 Cookie |
| 密码存储 | RSA 公钥加密存库；登录时用**明文**与解密值比对 | 前端明文提交；造数需 RSA 加密 |
| 角色模型 | `STUDENT=1`、`ADMIN=3`；`ROLE_STUDENT`/`ROLE_ADMIN` | 垂直越权测试依据 |
| 放行白名单 | `/api/wx/**`、`/api/admin/upload/configAndUpload`、`/api/admin/upload/auth`、`/api/student/user/register` | 白名单接口免登录，需重点验证 |
| 权限规则 | `/api/admin/**` 需 ADMIN；`/api/student/**` 需 STUDENT | 越权用例依据 |

## 4. 需求规则提取（DR/BR/PR）

### 4.1 业务规则（BR）

| 编号 | 规则 | 来源 |
|------|------|------|
| BR-01 | 用户登录成功返回 code=1 并下发会话；失败返回 402 | `RestAuthenticationProvider` |
| BR-02 | 用户名唯一，重复注册返回 code=2「用户已存在」 | `UserController.register` |
| BR-03 | 学生注册默认角色 STUDENT、状态启用 | `RoleEnum.STUDENT(1)` |
| BR-04 | 单选题/判断题正确答案必填，否则参数校验错误 | `validQuestionEditRequestVM` |
| BR-05 | 填空题各空分值之和须等于题目总分 | 同上 |
| BR-06 | 组卷试卷标题项至少 1 个，标题名非空 | `@Size(min=1)`/`@NotBlank` |
| BR-07 | 任务试卷每学生只能作答一次 | `calculateExamPaperAnswer` |
| BR-08 | 单/判断题按 `correct` 自动判分；多选按选项集合比对 | `setSpecialFromVM` |
| BR-09 | 消息接收人至少 1 个，标题/内容非空 | `MessageSendVM` |
| BR-10 | 学科/题目/试卷/用户删除均为**逻辑删除**（deleted=1） | Mapper `updateByIdFilter` |

### 4.2 权限规则（PR）

| 编号 | 规则 |
|------|------|
| PR-01 | 未登录访问受保护接口 → 401 |
| PR-02 | 学生访问 `/api/admin/**` → 502 |
| PR-03 | 管理员访问 `/api/student/**` → 502/401 |

### 4.3 数据规则（DR）

| 编号 | 规则 |
|------|------|
| DR-01 | 分页参数 `pageIndex/pageSize` 继承自 `BasePage` |
| DR-02 | 试卷类型：`1=固定`、`4=时段`、`6=任务`；题型：`1单选 2多选 3判断 4填空 5简答` |
| DR-03 | 用户状态：`1=启用 2=禁用` |

## 5. 需求缺口与假设（标注「待确认」）

| 编号 | 缺口描述 | 严重程度 | 测试假设 |
|------|----------|----------|----------|
| GAP-01 | 学生拉卷接口应返回题目**不含标准答案**，代码层面 `ExamPaperEditRequestVM` 复用管理端结构，未做字段裁剪 | **高** | 按「不应泄露 correct」设计用例，已实测**泄露**（见 DEF-001） |
| GAP-02 | 答卷提交 `answerSubmit` 是否校验答卷归属（只能交自己的） | 中 | 假设需校验，设计水平越权用例 |
| GAP-03 | 学生读取答卷/消息 `read/{id}` 未显式校验归属 | 中 | 假设需校验，设计越权用例 |
| GAP-04 | CSRF 被 `disable()` 关闭，依赖会话 Cookie 存在 CSRF 风险 | 中 | 记录为风险项，人工评估 |
| GAP-05 | 分页 pageSize 无上限，可能被用于拖库 | 低 | 按边界设计用例 |
| GAP-06 | 密码 RSA 私钥明文硬编码在 `application.yml` | 中 | 记录为配置安全风险 |

## 6. 测试标准（验收标准）

| 维度 | 验收标准 |
|------|----------|
| **正确性** | 功能接口返回结构与业务规则一致，成功率 100% |
| **异常性** | 非法入参返回业务错误码（501/502），**不出现 500 堆栈** |
| **安全性** | 越权访问被拦截；无 SQL 注入、密码泄露、答案泄露 |
| **性能** | 单接口 P95 响应 ≤ 1000ms（本地环境） |
| **可靠性** | 连续调用无内存泄漏、无状态污染 |

## 7. 风险评估（Top 5）

| 排序 | 风险 | 影响 | 等级 | 对策 |
|------|------|------|------|------|
| 1 | 学生端泄露标准答案 | 考试形同虚设，可作弊满分 | **严重** | 已确认缺陷 DEF-001，须接口字段裁剪 |
| 2 | 垂直越权（学生调管理接口） | 数据被篡改 | 高 | Security 已拦截，回归验证 |
| 3 | 水平越权（读他人答卷/消息） | 隐私泄露 | 高 | 需补校验，人工验证 |
| 4 | 参数校验缺失导致 500 | 服务暴露内部信息 | 中 | 异常用例覆盖 |
| 5 | CSRF 防护关闭 | 会话劫持 | 中 | 依赖 SameSite/前端防护 |
