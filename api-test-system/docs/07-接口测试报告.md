## 4. 关键验证结论

### ✅ 通过项

1. **认证链路**：正确账号登录返回 code=1 并下发 JSESSIONID；错密码返回 402；未登录访问受保护接口返回 401。
2. **权限模型**：学生访问 `/api/admin/**` 被拦截返回 502；管理员访问 `/api/student/**` 被拒绝；未登录访问管理接口返回 401。
3. **参数校验**：单选题缺正确答案返回 501；消息接收人为空返回 501；答卷缺字段返回参数校验错误；全流程**未出现 500 堆栈**。
4. **弱口令防护（部分）**：SQL 注入串 `admin' OR '1'='1` 无法登录；查询参数注入安全返回空结果。
5. **数据脱敏**：用户列表/当前用户响应**不含 password 字段**。
6. **业务闭环**：管理员组卷→学生按标准答案作答→**得分=满分(10分)**，判分逻辑正确。
7. **消息闭环**：管理员发送消息后学生未读数 +1，读取后 -1，状态一致。

### ❌ 失败项 / 缺陷

| 编号 | 标题 | 等级 | 状态 |
|------|------|------|------|
| **DEF-001** | 学生端拉取试卷详情接口泄露标准答案字段 `correct` | **严重 S1** | 待修复（详见缺陷记录） |

**复现证据**（学生 student 调用 `/api/student/exam/paper/select/1`）：

```json
{
  "code": 1, "message": "成功",
  "response": { "titleItems": [ { "questionItems": [
      { "id": 1, "questionType": 2, "correct": "A,B", "title": "test" }
  ] } ] }
}
```

返回体中 `correct="A,B"` 即标准答案，学生可据此作弊。E2E 用例已证明按 `correct` 提交可得满分。

## 6. 测试结论与建议

**结论**：本次 API 测试整体质量良好，功能与权限控制基本符合需求，异常处理健壮（无 500）。
但存在 **1 个严重安全缺陷（答案泄露）须优先修复**；另有多项越权/CSRF/密钥硬编码风险建议整改。

**改进建议**：
1. 【严重】学生端拉卷接口应使用**独立 ViewModel 裁剪 `correct`/`analyze` 字段**，杜绝答案下发。
2. 【高】答卷 `read/{id}`、消息 `read/{id}` 增加**归属校验**（只能操作自己的资源）。
3. 【中】为分页 `pageSize` 设置上限（如 ≤200），防止大页拖库。
4. 【中】密码 RSA 私钥不应硬编码在配置文件中，改为密钥管理服务/环境变量。
5. 【中】评估 CSRF 风险，前端敏感操作增加令牌校验。
6. 【建议】将本次自动化套件接入 CI，实现接口变更即回归。
