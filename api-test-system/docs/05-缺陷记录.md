## DEF-001 · 学生端拉取试卷详情接口泄露标准答案【严重】

| 字段 | 内容 |
|------|------|
| **缺陷编号** | DEF-001 |
| **严重等级** | S1 严重（严重安全漏洞 / 核心业务失效） |
| **所属模块** | 学生考试 / 接口安全 |
| **接口** | `POST /api/student/exam/paper/select/{id}` |
| **前置条件** | 学生 student 登录（student/123456） |
| **复现步骤** | 1. 登录学生账号，获取 JSESSIONID<br>2. 调用 `POST /api/student/exam/paper/select/1`<br>3. 查看响应 `response.titleItems[].questionItems[].correct` |
| **实际结果** | 响应体返回了题目的标准答案，如 `"correct": "A,B"` |
| **预期结果** | 学生端拉卷接口**不应返回** `correct`（标准答案）、`analyze`（解析）等敏感字段 |
| **影响** | 学生可直接读取标准答案并作答，**考试完全失去意义**；已通过 E2E-001 证明按 `correct` 提交可得满分 |
| **根因分析** | `StudentExamPaperController.select()` 复用了管理端的 `ExamPaperEditRequestVM`（内含 `correct` 字段），未针对学生场景做字段裁剪/脱敏 |
| **修复建议** | 新建学生端专用 ViewModel（如 `ExamPaperReadStudentVM`），仅返回 `id/questionType/title/items/score` 等作答必需字段，**剔除 `correct`、`analyze`**；或对 `correct` 字段在序列化时置空 |
| **证据** | 见 `reports/evidence_answer_leak.txt` 与接口测试报告第 4 节 |

## DEF-002 · 答卷/消息读取接口缺少归属校验（水平越权风险）【高】

| 字段 | 内容 |
|------|------|
| **严重等级** | S2 高 |
| **接口** | `POST /api/student/exampaper/answer/read/{id}`、`POST /api/student/user/message/read/{id}` |
| **复现步骤** | 1. 用 student 产生一条答卷/消息<br>2. 用 student2(ki) 携带自己的会话调用 `read/{id}`（id 为 student 的资源） |
| **实际结果** | 代码层面 `selectById(id)` 未校验 `createUser/receiveUser` 是否为当前用户（待人工确认） |
| **预期结果** | 仅允许读取/操作归属于当前登录用户的资源，否则返回拒绝或空 |
| **影响** | 存在越权读取他人答卷、标记他人消息已读的风险 |
| **修复建议** | Service 层增加归属断言：`resource.getCreateUser().equals(currentUser.getId())` |

## DEF-003 · 分页参数 pageSize 无上限【中】

| 字段 | 内容 |
|------|------|
| **严重等级** | S3 中 |
| **接口** | 所有分页接口（继承 `BasePage`） |
| **复现步骤** | 调用 `POST /api/admin/user/page/list`，`pageSize=100000` |
| **实际结果** | 接口正常返回（可能一次性拉取大量数据） |
| **预期结果** | pageSize 超过阈值（如 200）应截断或报错 |
| **影响** | 可能被恶意利用批量拉取数据、拖慢服务 |
| **修复建议** | 在 `BasePage` 或拦截器中对 pageSize 设上限 |

## DEF-004 · 密码 RSA 私钥硬编码【中】

| 字段 | 内容 |
|------|------|
| **严重等级** | S3 中 |
| **位置** | `application.yml` → `system.pwdKey.privateKey` |
| **问题** | RSA 私钥以明文形式硬编码在配置文件中并提交到代码库 |
| **影响** | 私钥泄露即可解密所有用户密码（本项目密码加密仅防明文存储） |
| **修复建议** | 私钥通过环境变量/密钥管理服务注入，不落库不入库 |

---

## DEF-005 · CSRF 防护被关闭【中】

| 字段 | 内容 |
|------|------|
| **严重等级** | S3 中 |
| **位置** | `SecurityConfigurer` → `.csrf().disable()` |
| **问题** | 系统基于会话 Cookie 鉴权，却关闭了 CSRF 防护 |
| **影响** | 存在跨站请求伪造风险，攻击者可诱导已登录用户执行敏感操作 |
| **修复建议** | 评估并启用 CSRF Token，或对写操作增加二次校验（如 SameSite=Strict + 自定义头校验） |
