## 1. 手工验证关键链路（已执行）

### MT-01 管理员登录并访问仪表盘

| 项 | 内容 |
|----|------|
| 对应用例 | AUTH-001 |
| 步骤 | `curl -c cookie.txt -X POST /api/user/login -d '{"userName":"admin","password":"123456","remember":false}'` → 再带 cookie 请求 `/api/admin/dashboard/index` |
| 实测结果 | 登录返回 `{"code":1,...,"userName":"admin"}`，Cookie 写入 JSESSIONID；仪表盘返回 `examPaperCount:8,questionCount:12,...` |
| 结论 | ✅ 通过 |

### MT-02 学生拉取试卷详情（发现缺陷）

| 项 | 内容 |
|----|------|
| 对应用例 | EXAM-003 / SEC-007 |
| 步骤 | student 登录 → `POST /api/student/exam/paper/select/1` |
| 实测结果 | 响应 `titleItems[].questionItems[].correct = "A,B"`，**标准答案泄露** |
| 结论 | ❌ 失败，登记 DEF-001（严重） |

### MT-03 教师端答卷列表

| 项 | 内容 |
|----|------|
| 对应用例 | E2E-003 |

| 实测结果 | 返回答卷分页结构，含 userScore/systemScore/paperName |
